## Linking a JavaScript File

### Inline JavaScript and linking JavScript

```html
<html>
  <head>
    <title>Linking JavaScript</title>
  </head>
  <body>
    <h1>Hello World</h1>

    <!--This Is Inline javascript  -->
    <script>
      console.log("Hello World");
    </script>

    <!-- This is Connected to JavaScript File -->
    <script src="script.js"></script>
  </body>
</html>
```

```js
// scripts.js

console.log("Hello World");
```
