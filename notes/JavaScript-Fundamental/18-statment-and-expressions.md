## Statement and expressions

### Expressions

Expressions is piece of code that produce a value.

```js
3 + 4;
1971;
true && false && !false;
```

### Statements

Statements is like a bigger piece of code that is executedad which does not produce a value on itself.

```js
if (23 > 10) {
  const str = "23 is bigger";
  // this is not value, this is just declare something
}
```
