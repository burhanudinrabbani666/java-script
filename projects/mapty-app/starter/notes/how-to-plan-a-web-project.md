## How to Plan a Web Project

1. User Stories

user story is basically a descriptio of the application's functionality from the user's perspective. And then all the user stories put together will clearly describe the functionality of the entire application.

Common Format: As a [Type of User], I want [an Action], so that [a Benefit]

Exm: **As a** user. **I want to** log My running workout with location, distance, time space and steps/minutes, **so i can keep** a log of all my running
